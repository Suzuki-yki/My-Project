\- Dreamcore

\---



\# 1. PRODUCT POSITIONING



Persona Space is NOT:



\- A DeFi platform

\- A Web3 dashboard

\- A crypto admin panel

\- A trading interface

\- A finance product



Persona Space IS:



\# “A futuristic AI companion identity space.”



The user experience should feel like:



\# “Entering a personal AI cyber room.”



The UI must feel:



\- emotional

\- immersive

\- futuristic

\- soft

\- dreamlike

\- alive



\---



\# 2. CORE VISUAL PHILOSOPHY



The product must NEVER feel like:



\- Binance

\- Uniswap

\- OKX

\- Generic SaaS Dashboard

\- Traditional Web3 UI



Avoid:



\- hard edges

\- cold tech feeling

\- dense financial layouts

\- heavy data panels

\- hacker style cyberpunk

\- over-engineered dashboard structures



The entire interface should feel like:



\# “A living AI companion space.”



\---



\# 3. GLOBAL DESIGN LANGUAGE



The visual atmosphere should feel like:



\- futuristic anime room

\# “Living together with an AI companion.”

\# 12. GLASSMORPHISM SYSTEM



All floating panels must use:



```css

background: rgba(255,255,255,0.05);



backdrop-filter: blur(20px);



border:

1px solid rgba(255,255,255,0.08);

```



\---



\## Glassmorphism Rules



Avoid:



\- solid blocks

\- opaque panels

\- heavy containers

\- harsh borders



The interface must feel:



\# “soft and dreamlike.”



\---



\# 13. BORDER RADIUS RULES



DO NOT use small radius.



Recommended:



```css

border-radius: 24px;

```



or



```css

border-radius: 32px;

```



The interface should feel:



\- soft

\- emotional

\- futuristic



\---



\# 14. SHADOW SYSTEM



Use:



\- soft inner glow

\- subtle neon shadow

\- atmospheric lighting



\---



\## Recommended Shadow



```css

box-shadow:

0 0 30px rgba(193,143,164,0.15);

```



\---



\## Avoid



\- hard shadows

\- material UI shadows

\- strong depth contrast
